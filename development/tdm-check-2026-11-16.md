# Text-and-data-mining reservations of the data sources — check of 2026-11-16

EU Directive 2019/790, art. 4 lets a rightholder reserve text and data mining « in an appropriate manner, such as
machine-readable means ». This note records what each source of Pépite's data said about it **on 2026-11-16**. The
check was made **after** the data was collected (2026-11-08 to 2026-11-16), so it says nothing certain about the day each
file was downloaded; it is not back-dated. Raw results (JSON) are kept outside the repository.

**Method:** a generic HTTP client fetched, for each host, `robots.txt`, `/.well-known/tdmrep.json` (W3C TDMRep), `/ai.txt`
and the page or file used, and looked for `tdm-reservation` / `tdm-policy` / `X-Robots-Tag` headers and meta tags,
`Content-Signal` lines and rules naming AI crawlers. `robots.txt` rules are crawler instructions: they are recorded,
but a `Disallow` alone is not read as a TDM reservation unless it is stated as one.
