====================================================================
  PÉPITE — DÉPLOIEMENT DANS UN ÉTABLISSEMENT
  Guide pour le service informatique
====================================================================

Pépite est un programme de prédiction de mots pour élèves, logiciel
libre (GPL-3.0-or-later). Un seul fichier d'installation :
Pepite-<version>-installation.exe (Inno Setup, pas de MSI).
Windows 11 64 bits (x64) seulement.


1. AUCUN FLUX RÉSEAU
--------------------------------------------------------------------
  Ni l'installation ni Pépite n'utilisent le réseau : pas de
  téléchargement, pas de mise à jour automatique, pas de
  télémétrie, pas de licence à activer. Aucune règle de pare-feu ni
  de proxy n'est nécessaire. Les mises à jour se font en déployant
  la nouvelle version par-dessus l'ancienne.


2. INSTALLATION SANS QUESTION (TOUS LES POSTES)
--------------------------------------------------------------------
  Pour tous les utilisateurs (conseillé, en administrateur ou en
  compte SYSTEM) :

    Pepite-<version>-installation.exe /VERYSILENT /SUPPRESSMSGBOXES
        /NORESTART /ALLUSERS /CONFIG="\\serveur\pepite\settings.json"
        /LOG="C:\Windows\Temp\pepite-install.log"

  Paramètres :
    /VERYSILENT /SUPPRESSMSGBOXES  aucune fenêtre, aucune question
    /NORESTART                     jamais de redémarrage
    /ALLUSERS                      pour tous les utilisateurs
                                   (C:\Program Files\Pepite-Prediction)
    /CURRENTUSER                   pour le compte qui lance seulement
                                   (%LOCALAPPDATA%\Programs\Pepite-Prediction)
    /DIR="<dossier>"               autre dossier : seulement pour une
                                   installation « pour moi »
                                   (/CURRENTUSER). Pour tous les
                                   utilisateurs, Pépite s'installe
                                   uniquement dans un dossier placé
                                   directement dans « Program Files »
                                   (C:\Program Files\Pepite-Prediction) ;
                                   un autre dossier est refusé
                                   (code 7). Une ancienne version de
                                   test installée pour tous dans un
                                   autre dossier : désinstallez-la
                                   d'abord.
    /COMPONENTS="images,voix\siwis"  composants : app (toujours),
                                   images (pictogrammes), voix\siwis
                                   et voix\pierre (voix naturelles). Exemple sans
                                   voix ni images : /COMPONENTS="app"
    /TASKS="demarrage,pepite"      tâches : demarrage (démarrer avec
                                   Windows), pepite (ouvrir les
                                   fichiers .pepite), bureau (icône
                                   sur le Bureau). Exemple sans
                                   démarrage automatique :
                                   /TASKS="pepite"
    /CONFIG="<fichier>"            configuration de l'établissement
                                   (voir § 5), seulement avec /ALLUSERS
                                   (sans /ALLUSERS : refusée, code 2).
                                   Chemin absolu recommandé ; un chemin
                                   relatif est cherché dans le dossier
                                   courant, puis à côté de l'installeur
    /LOG="<fichier>"               journal de l'installation
    /FORCECLOSEAPPLICATIONS        fermer de force un Pépite ouvert
                                   qui ne s'est pas fermé seul
    /NOLANCER                      ne pas relancer Pépite après une
                                   mise à jour silencieuse (voir
                                   ci-dessous)

  Une installation silencieuse ne lance pas Pépite : chaque
  utilisateur l'a à sa prochaine ouverture de session (démarrage avec
  Windows, clé Run de HKLM pour une installation pour tous). Une
  seule exception (à partir de 0.11.0) : une mise à jour silencieuse
  qui a fermé le Pépite ouvert du compte qui lance l'installation le
  relance pour ce compte, sans droits d'administrateur
  (« --autostart »). /NOLANCER l'empêche. En compte SYSTEM (Intune,
  SCCM), rien n'est relancé : chaque compte a la nouvelle version à
  sa prochaine ouverture de session. Lancée depuis une console déjà
  en administrateur, l'installation relancerait Pépite avec ces
  droits : ajoutez /NOLANCER.

  Mise à jour : la nouvelle version s'installe par-dessus l'ancienne,
  dans le même mode et le même dossier, avec les mêmes composants et
  tâches (sauf paramètres /COMPONENTS ou /TASKS). Les réglages, les
  profils et les mots des élèves sont gardés ; au premier démarrage
  de la nouvelle version, Pépite en fait une copie (voir § 8). Une
  version plus ancienne que celle installée est refusée (code 1,
  voir § 4 pour revenir en arrière).

  Un Pépite ouvert est fermé proprement avant la mise à jour (même
  utilisateur). Attention : lancée en compte SYSTEM (Intune, SCCM),
  l'installation ne peut pas fermer le Pépite ouvert dans la session
  d'un élève (Windows le refuse d'une session à l'autre, même avec
  /FORCECLOSEAPPLICATIONS) : la mise à jour s'arrête alors sans rien
  changer (code 5, l'ancienne version reste installée). Déployez les
  mises à jour quand personne n'est connecté (au démarrage du poste,
  ou après la fermeture des sessions), ou faites quitter Pépite dans
  chaque session avant le déploiement, ou relancez le déploiement.

  Ne mélangez pas les deux modes : si Pépite est déjà installé « pour
  moi » sur un compte, l'installation « pour tous » est refusée sur
  ce compte (et inversement), code de sortie 1. Désinstallez d'abord
  les installations par utilisateur.


3. CODES DE SORTIE
--------------------------------------------------------------------
    0   installation réussie
    1   l'installation n'a pas démarré (dont : Pépite déjà installé
        dans l'autre mode ; une version plus récente de Pépite est
        déjà installée — désinstallez-la d'abord pour revenir en
        arrière, voir § 4 ; Windows 10 ; processeur non x64)
    2   Pépite est installé, mais le fichier /CONFIG a été refusé
        (JSON non valable ou schéma inconnu, installation sans
        /ALLUSERS, ou dossier %PROGRAMDATA%\Pepite-Prediction déjà
        créé par un autre compte que les administrateurs — à
        supprimer, puis relancer) : aucun fichier de configuration
        n'a été écrit
        (sans /CONFIG, 2 = annulé par l'utilisateur avant
        l'installation : impossible en /VERYSILENT)
    6   processus d'installation terminé de force depuis l'outil de
        compilation (ne survient pas lors d'un déploiement)
    7   installation refusée avant la copie : pour tous les
        utilisateurs, un dossier qui n'est pas placé directement
        dans « Program Files » (/DIR), ou un dossier qui est un
        lien (voir le journal /LOG)
    3, 4, 8   erreur pendant la préparation ou l'installation
        (voir le journal /LOG)
    5   annulé pendant l'installation (dont : en compte SYSTEM, un
        Pépite ouvert dans la session d'un utilisateur ; rien n'est
        changé, voir § 2)


4. DÉSINSTALLATION SANS QUESTION
--------------------------------------------------------------------
  Le désinstallateur est dans le dossier d'installation :

    "C:\Program Files\Pepite-Prediction\unins000.exe" /VERYSILENT
        /SUPPRESSMSGBOXES /NORESTART

  Sans autre paramètre, AUCUNE donnée des élèves n'est supprimée.
    /SUPPRIMERDONNEES  supprime aussi les réglages, profils et mots
                       du compte qui lance la désinstallation
                       (%APPDATA%\Pepite-Prediction,
                       %LOCALAPPDATA%\Pepite-Prediction,
                       %APPDATA%\PredictKeyboard) ;
                       les autres comptes ne sont pas touchés
    /SUPPRIMERCONFIG   supprime aussi la configuration de
                       l'établissement (%PROGRAMDATA%\Pepite-Prediction)

  La commande exacte est aussi dans le registre :
  HKLM\Software\Microsoft\Windows\CurrentVersion\Uninstall\
  {999AA879-43C2-4C22-9785-691AA95A3455}_is1, valeur
  QuietUninstallString (HKCU pour une installation par utilisateur).

  Revenir à une version précédente : désinstallez sans
  /SUPPRIMERDONNEES (les données sont gardées), puis installez
  l'ancienne version. Une installation plus ancienne que celle en
  place est refusée (code 1) à partir de 0.11.0 ; les installations
  antérieures à 0.11.0 ne vérifient pas la version. À partir de
  0.11.0, une version qui trouve un fichier de réglages écrit par une
  version plus récente le lit sans jamais le réécrire.

  Installations « pour moi » restées sur un poste (avant de passer à
  une installation pour tous), en PowerShell administrateur :
    Get-ChildItem "$env:SystemDrive\Users\*\AppData\Local\Programs\Pepite-Prediction" -Directory -EA 0


5. CONFIGURATION DE L'ÉTABLISSEMENT (FACULTATIVE)
--------------------------------------------------------------------
  Un fichier JSON propose (« defaults ») ou impose (« locked ») des
  réglages à tous les comptes du poste. Exemple complet :
  exemple-etablissement.json (taille L, police OpenDyslexic,
  indicateur d'orthographe imposé, pas de fenêtre de bienvenue,
  deux mots à ne jamais proposer — à remplacer par les vôtres).

    {
      "schema": 1,
      "defaults": { "words": { "count": 6, "size": "L" } },
      "locked":   { "words": { "spellingIndicator": true } }
    }

  Réglages possibles (mêmes noms que %APPDATA%\Pepite-Prediction) :
    words.count (1 à 8), words.size (S, M, L, XL), words.pictures,
    words.keys (F1-F8, off), words.font (segoe-ui, opendyslexic,
    lexend, andika), words.spacing (normal, wider, widest),
    words.spellingIndicator, words.namePictures,
    words.clickMode (clic sur un mot : insert = insérer tout de suite,
      listenFirst = 1er clic écouter / 2e clic insérer, listenDouble =
      clic écouter / double-clic ou clic droit insérer ; par défaut
      listenDouble),
    words.keysListenFirst (touches F1 à F8 : true = 1er appui écouter /
      2e insérer, par défaut ; false = insérer tout de suite),
    words.listenShiftKeys (Maj + F1 à F8 : écouter le mot),
    words.listenButton (bouton haut-parleur sous chaque mot),
    words.soundPairs.chj, .fv, .kg, .td, .pb (« Sons que l'élève
      confond » : true = Pépite propose aussi le mot où ce son est
      remplacé par son voisin, « chardin » -> jardin ; par défaut
      chj true, les quatre autres false ; chaque paire se règle ou
      se bloque seule, par exemple
      "locked": { "words": { "soundPairs": { "chj": false } } }),
    bar.position (caret, top, bottom, free),
    text.punctuationSpace (french, french-nbsp, none),
    speech.speakInserted, speech.speakWords,
    speech.speakSentences, speech.voice, speech.rate, speech.volume,
    speech.rereadEdits, reading.enabled,
    reading.clipboardFallback (copie de la sélection par Ctrl+C ;
      absent ou null = dans LibreOffice Writer seulement, par
      défaut ; true = partout ; false = jamais ; jamais dans
      LibreOffice Calc, quelle que soit la valeur ; dans Writer, la
      sélection est lue directement et la copie ne sert que si la
      lecture directe échoue),
    reading.pictures, start.welcome.

  Mots à ne jamais proposer (dans « locked » seulement) :
    "locked": { "motsExclus": [ "abcde", "fghij" ] }
  Une liste de mots (500 au plus, 40 lettres au plus chacun ;
  lettres, trait d'union ou apostrophe au milieu) que Pépite ne
  propose jamais sur ce poste, en plus de sa liste intégrée et des
  « Mots à ne jamais proposer » de la Classe (Espace enseignant →
  Mots → « Classe », derrière le code enseignant). Un élève qui tape
  un de ces mots l'écrit normalement. Dans cette liste, les mots du
  fichier sont affichés « Réglé par l'administrateur ». Sans Espace
  enseignant (un seul utilisateur), ce fichier est le seul moyen
  d'ajouter des mots. La liste intégrée ne peut pas être désactivée.
  « Pepite.exe --check-config » indique combien d'entrées de
  motsExclus sont ignorées (pas un mot, ou plus de 500).

  L'installation (avec /ALLUSERS) :
    - vérifie le fichier avec "Pepite.exe --check-config <fichier>"
      (code 0 valable, 2 JSON non valable ou schéma inconnu,
      3 illisible) ; un fichier refusé n'est jamais écrit ;
    - le copie dans %PROGRAMDATA%\Pepite-Prediction\settings.json ;
    - protège le dossier : propriétaire Administrateurs, sans
      héritage, Administrateurs et SYSTEM contrôle total,
      Utilisateurs lecture seule. Pépite ignore un fichier que
      d'autres comptes pourraient modifier ;
    - refuse (code 2) un dossier %PROGRAMDATA%\Pepite-Prediction
      déjà présent qui est un lien ou qui n'appartient pas aux
      administrateurs : supprimez-le, puis relancez l'installation.
  Sans /CONFIG, un fichier déjà présent est gardé tel quel. Vous
  pouvez vérifier un fichier avant le déploiement (Pepite.exe est
  une application fenêtrée : attendez sa fin pour lire le code) :
    invite de commandes :
      start /wait "" "C:\Program Files\Pepite-Prediction\Pepite.exe" --check-config settings.json
      echo %ERRORLEVEL%
    PowerShell :
      (Start-Process "C:\Program Files\Pepite-Prediction\Pepite.exe" -ArgumentList '--check-config','settings.json' -Wait -PassThru).ExitCode


6. INTUNE (APPLICATION WIN32), SCCM / CONFIGMGR, SCRIPTS
--------------------------------------------------------------------
  Pas de MSI : pas de déploiement par GPO « Installation de
  logiciel ». Intune Win32, SCCM ou un script de démarrage
  conviennent.

  Intune (Win32, .intunewin) :
    Installation  : Pepite-<version>-installation.exe /VERYSILENT
                    /SUPPRESSMSGBOXES /NORESTART /ALLUSERS
    Désinstallation : "C:\Program Files\Pepite-Prediction\unins000.exe"
                    /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
    Comportement  : Système (System context)
    Redémarrage   : aucun
    Règle de détection : fichier
                    C:\Program Files\Pepite-Prediction\Pepite.exe,
                    version de fichier >= <version>.0
                    (ou clé de registre HKLM ...\Uninstall\
                    {999AA879-43C2-4C22-9785-691AA95A3455}_is1,
                    valeur DisplayVersion = <version>)
    Codes de retour : 0 succès ; 2 à signaler (configuration refusée).
  Pour /CONFIG, mettez settings.json dans le paquet .intunewin et
  passez /CONFIG="settings.json".


7. APPLOCKER, SMARTSCREEN, ANTIVIRUS
--------------------------------------------------------------------
  - AppLocker / WDAC : les règles par défaut autorisent
    C:\Program Files\ mais pas %LOCALAPPDATA%\Programs : installez
    avec /ALLUSERS. Les versions de test ne sont pas signées : une
    règle « éditeur » est impossible, utilisez une règle de chemin
    (C:\Program Files\Pepite-Prediction\*) ou de hachage.
  - SmartScreen / Smart App Control : la version de test non signée
    peut être bloquée au premier lancement de l'installation. Un
    déploiement par Intune / SCCM / script n'est pas concerné par
    SmartScreen (pas de fichier « venant d'Internet »).
  - Pépite surveille le clavier (pour proposer les mots) et insère
    du texte : certains antivirus peuvent le signaler. Rien n'est
    enregistré ni envoyé ; ajoutez une exclusion si nécessaire.
  - LibreOffice Writer (25.2 ou plus récent ; testé avec 26.8.3 et
    25.2.7) : Pépite lit le texte par l'interface d'accessibilité
    IAccessible2 de LibreOffice, avec les composants de Windows
    (oleacc.dll, ia2comproxy.dll). Rien à installer, enregistrer ni
    configurer, aucune option de LibreOffice n'est changée. La
    variable d'environnement SAL_ACCESSIBILITY_ENABLED=0 coupe
    l'accessibilité de LibreOffice : Pépite y fonctionne alors en
    mode « touches seulement » (sans barre dans les fenêtres de
    dialogue de LibreOffice). Calc et Impress : touches seulement.
    La sélection de Writer est lue par la même interface, sans
    presse-papiers. Si LibreOffice ne répond plus un moment, Pépite
    passe en « touches seulement » 10 s (puis 20 s, 40 s) et réessaie
    ensuite.


8. DONNÉES PERSONNELLES (RGPD)
--------------------------------------------------------------------
  - Tout reste sur le poste : réglages et profils dans
    %APPDATA%\Pepite-Prediction de chaque compte, sauvegardes dans
    %LOCALAPPDATA%\Pepite-Prediction\sauvegardes (une par jour, une
    avant chaque suppression ou import, et une au premier démarrage
    de chaque nouvelle version : profils-<date>-mise-a-jour.zip ; les
    5 dernières de chaque sorte sont gardées). Rien n'est envoyé.
  - Les profils contiennent les prénoms des élèves (et, si
    l'enseignant en ajoute, des listes de mots). Pas de photo
    (seulement des pictogrammes ou dessins).
  - Pépite n'enregistre pas ce que les élèves écrivent (sauf le mode
    journal --log, réservé aux tests, qui ne garde jamais les mots
    de passe ni les prénoms des profils ; un prénom tapé dans le
    texte y est enregistré comme le reste).
  - Les fichiers .pepite (export des profils) contiennent les
    prénoms : à garder sur un support de l'établissement.
  - Effacement : désinstallation avec /SUPPRIMERDONNEES, ou
    suppression du dossier %APPDATA%\Pepite-Prediction du compte.


9. RÉSUMÉ DES EMPLACEMENTS
--------------------------------------------------------------------
    Programme (pour tous)   C:\Program Files\Pepite-Prediction
    Programme (par compte)  %LOCALAPPDATA%\Programs\Pepite-Prediction
    Démarrage avec Windows  HKLM (ou HKCU)\Software\Microsoft\Windows\
                            CurrentVersion\Run, valeur
                            « Pepite-Prediction »
                            = "<dossier>\Pepite.exe" --autostart
    Fichiers .pepite        HKLM (ou HKCU)\Software\Classes\.pepite
                            -> Pepite-Prediction.Profils
    Configuration           %PROGRAMDATA%\Pepite-Prediction\settings.json

                            %LOCALAPPDATA%\Pepite-Prediction
