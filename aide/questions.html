Un souci ?

Les petits problèmes les plus courants, et quoi faire.

La barre n'apparaît pas

  • Le biscuit près de l'horloge est gris ? Pépite est en pause : clique dessus, puis sur Reprendre.
  • Tu écris un mot de passe ? C'est normal : Pépite se tait.
  • Pas de biscuit du tout ? Pépite n'est pas démarré. Ouvre Pépite depuis le menu Démarrer.
  • Dans une console ou une fenêtre de bureau à distance, Pépite ne fait rien. C'est voulu.
  • Un programme lancé « en tant qu'administrateur » ne laisse pas Pépite écrire dedans.

Je ne trouve pas le biscuit

Windows cache parfois les petites icônes. Clique sur la flèche ^ à côté de l'horloge : le biscuit est là.

Pour le garder toujours visible, un adulte peut ouvrir Paramètres > Personnalisation > Barre des tâches > Autres icônes de barre d’état système.

La touche F1 fait autre chose

Les touches F1 à F8 choisissent un mot seulement quand la barre est là. Sinon, elles font leur travail habituel.

Dans la fenêtre Réglages, F1 ouvre cette aide.

Sur certains portables, il faut appuyer en même temps sur la touche Fn.

Tu as besoin des touches F pour un jeu ou un programme ? Décoche Touches F1 à F8 pour insérer dans les réglages. Le clic marche toujours.

Le mot ne s'écrit pas du premier coup

C'est normal : un clic dit le mot. Pour l'écrire, fais un double-clic ou un clic droit.

Avec une touche, la première fois, Pépite dit le mot et l'entoure d'un cadre blanc. Appuie encore sur la même touche : il l'écrit.

Ton double-clic dit le mot deux fois ? Clique un peu plus vite, ou fais un clic droit. Un adulte peut régler la vitesse du double-clic dans Windows (Paramètres, souris).

Tu préfères écrire tout de suite ? Un adulte peut choisir Insérer tout de suite pour le clic et pour les touches dans les réglages.

Dans Word, Maj + F3 change les majuscules. Si Maj + F1…F8 : écouter le mot est cochée, ces touches disent le mot quand la barre est là. Cache la barre avec Échap, puis appuie sur Maj + F3.

Je n'entends rien

  • Vérifie le son de l'ordinateur et le casque.
  • Dans les réglages, clique sur Écouter.
  • Juste après le démarrage, la voix met quelques secondes à se préparer. Le biscuit dit alors « chargement de la voix » quand la souris passe dessus.
  • Dans un champ de mot de passe, ou quand Pépite ne sait pas si le champ est sûr, il se tait.

Les mots proposés ne me conviennent pas

  • Continue à taper : la barre change à chaque lettre.
  • Échap cache la barre.
  • Il manque un mot ? Ajoute-le.
  • Tu fais toujours la même faute ? Utilise Mes fautes.

On me demande un code

À l'école, certains choix sont protégés par le code enseignant. Demande à ton enseignant.

Pour les adultes : le code enseignant et le code de secours.

Pépite est déjà démarré

Pépite marchait déjà. Rien de grave : il n'en démarre pas un deuxième. La fenêtre te propose Ouvrir les Réglages ou Aide.

Windows a protégé votre ordinateur

Ce message vient pendant l'installation. C'est l'affaire d'un adulte : voir Installer Pépite.

Dans LibreOffice

  • Dans Writer, lire un texte marche : sélectionne le texte, la barre de lecture apparaît. Pépite fait une copie de la sélection, puis remet le presse-papiers comme avant. Un mot coupé par ta sélection reste coupé.
  • Dans Calc, Pépite ne lit pas les cellules sélectionnées : il ne copie jamais rien dans LibreOffice Calc.
  • La barre s'affiche près de la souris : LibreOffice ne dit pas à Pépite où est le curseur.
  • Devant ! ? : ;, c'est LibreOffice qui met l'espace.
  • Un mot choisi avec le rond ≈ s'ajoute à côté du mot mal écrit, sans le remplacer : efface l'ancien mot.

Sans souris, avec un lecteur d'écran

  • Sans souris : Windows+B, puis les flèches jusqu'au biscuit, puis Entrée ouvre le menu de Pépite.
  • Lecteur d'écran : les réglages ont tous un nom lisible (Narrateur, NVDA).
  • Lecteur d'écran, accès vocal ou contacteur : ils peuvent activer un mot de la barre (par exemple, dis cliquer maison avec l'accès vocal). Ils suivent le réglage Touches F1–F8 : la première fois, Pépite dit le mot et l'entoure d'un cadre blanc ; la deuxième fois, il l'écrit. Avec Insérer tout de suite, le mot s'écrit du premier coup. Cela marche même quand les touches F1 à F8 sont décochées.
  • Cette aide s'agrandit avec Ctrl++. La touche Tab passe d'un lien à l'autre. Les cases en haut de page changent les lettres et la taille.

Signaler un problème

Parle-en à un adulte. Il peut écrire aux auteurs de Pépite sur github.com/pepite-labs/pepite, rubrique « Issues ».

On n'y met jamais de prénom, de texte d'élève ni de copie d'écran avec des noms.
