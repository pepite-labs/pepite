Installer Pépite

Installer, mettre à jour, désinstaller ; et ce qu'il faut savoir pour une école.

Configuration recommandée (provisoire)

  • Windows 11, 64 bits, processeur Intel ou AMD (pas les PC à processeur ARM). Windows 10 n'est pas pris en charge.
  • Mémoire : 8 Go conseillés. En dessous de 4 Go, l'installation affiche un avertissement.
  • Un disque SSD est conseillé.
  • Environ 460 Mo sur le disque avec les images et une voix naturelle.
  • Rien d'autre à installer, et aucune connexion Internet nécessaire.

Ces valeurs seront mesurées et précisées plus tard.

Installer

  1. Double-cliquez sur le fichier d'installation de Pépite.

  2. Si Windows affiche Windows a protégé votre ordinateur, voir plus bas.

  3. Choisissez Installer seulement pour moi (ce compte Windows, sans mot de passe administrateur) ou Installer pour tous les utilisateurs (tous les comptes ; il faut un compte administrateur ; dossier Program Files uniquement). Pour une école, choisissez « pour tous les utilisateurs ».

  4. Choisissez les composants et les tâches (voir ci-dessous), puis installez.

  5. À la fin, Lancer Pépite démarre Pépite. Son icône, le biscuit, est près de l'horloge (ou derrière la flèche « ^ »).

Vous pouvez vérifier le fichier avant de l'installer : son empreinte SHA-256 (commande PowerShell Get-FileHash) doit être celle du fichier SHA256SUMS.txt publié avec lui.

Composants et tâches

Images des mots (pictogrammes ARASAAC)
Les images au-dessus des mots. Sans elles, Pépite marche aussi.
Voix naturelles (sinon, la voix de Windows)
Siwis (voix féminine), la voix par défaut, et Pierre (voix masculine).
Démarrer Pépite avec Windows
Coché au départ. Pépite démarre à chaque ouverture de session, sans fenêtre : seulement une petite notification Pépite est prêt.
Ouvrir les fichiers .pepite (profils des élèves) avec Pépite
Un double clic sur un fichier exporté par l'Espace enseignant ouvre son import.
Créer une icône sur le Bureau
Non cochée au départ.

Au tout premier démarrage, une fenêtre Pépite est prêt ! montre où se trouve l'icône. En savoir plus ouvre la page Bienvenue de cette aide.

Windows a protégé votre ordinateur

Les versions actuelles de Pépite ne sont pas encore signées numériquement : Windows ne connaît pas encore leur auteur.

  • SmartScreen affiche Windows a protégé votre ordinateur : cliquez sur Informations complémentaires, puis sur Exécuter quand même.
  • Smart App Control peut bloquer le fichier sans proposer « Exécuter quand même ». Pépite ne peut alors pas être installé sur cet ordinateur : attendez la version signée.

Cette section restera ici tant que l'installation n'est pas signée.

Mettre à jour

Lancez l'installation de la nouvelle version. Elle dit Pépite 0.10.2 est déjà installé : il sera mis à jour en 0.11.0 (avec vos numéros de version) et rappelle le dossier, les composants et les tâches de l'installation actuelle. Cliquez sur Mettre à jour, puis sur Terminer : c'est tout. Pépite est fermé pendant la mise à jour ; vos choix, les réglages et les profils sont gardés. Pépite ne se met jamais à jour tout seul.

  • Pour changer les composants ou les tâches, cochez d'abord Modifier les choix : les pages habituelles reviennent.
  • Au premier démarrage de la nouvelle version, Pépite copie les profils et les réglages dans le dossier des sauvegardes (voir Où sont les données ?).
  • Une version plus ancienne que celle installée est refusée. Pour revenir en arrière, désinstallez d'abord Pépite en répondant Non à la question sur les réglages (ils sont gardés), puis lancez l'installation de l'ancienne version.

Désinstaller

Paramètres Windows → Applications → Applications installées → Pépite → Désinstaller.

Une question est posée : Supprimer aussi les réglages, les profils des élèves et leurs mots enregistrés sur ce compte Windows ? Par défaut, non : ils sont gardés pour une prochaine installation.

Où sont les données ?

  • Réglages, profils et mots des élèves : %APPDATA%\Pepite-Prediction, pour chaque compte Windows.
  • Une sauvegarde par jour des profils, et une au premier démarrage de chaque nouvelle version : %LOCALAPPDATA%\Pepite-Prediction\sauvegardes.
  • Configuration de l'établissement, facultative : %PROGRAMDATA%\Pepite-Prediction\settings.json.
  • Pépite n'écrit rien dans son dossier d'installation.

Installer dans une école

Le service informatique trouve tout dans le fichier DEPLOIEMENT.txt, installé à côté de Pépite : installation sans question sur tous les postes, codes de sortie, configuration de l'établissement (réglages imposés à tous les comptes), Intune, SCCM, AppLocker, données personnelles.

Le fichier LISEZ-MOI.txt résume l'installation et l'utilisation.
