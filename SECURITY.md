# Sécurité

## Signaler une faille

Utilisez **uniquement le signalement privé de GitHub** : onglet *Security* du dépôt → *Report a vulnerability*
(« private vulnerability reporting »). N'ouvrez pas de ticket public et ne publiez pas les détails avant la correction.
Il n'y a pas d'adresse e-mail de contact.

Indiquez la version de Pépite, la version de Windows, les étapes pour reproduire et l'effet constaté. N'y mettez
**aucune donnée d'élève**.

## Ce qui nous intéresse

- le crochet clavier global et l'insertion de texte dans les autres applications ;
- la protection des champs de mot de passe (ils ne doivent jamais être lus) ;
- l'import des fichiers `.pepite` (profils exportés) ;
- le fichier de configuration de l'ordinateur (`%PROGRAMDATA%`) et le code enseignant ;
- le programme d'installation et la désinstallation ;
- les paquets de données livrés (base de mots, voix, images, noms propres).

Le code enseignant protège contre les manipulations d'enfants ; ce n'est pas une frontière de sécurité contre un
administrateur de l'ordinateur.

## Versions suivies

Seule la dernière version publiée reçoit des corrections.
